# 公共表与本作表

## 职责

- `series/glossary.json`维护系列前作已确认、可复用的术语。
- `games/<本作>/work/glossary.locked.json`维护本作新增术语、待定项和特殊用法。
- `series/glossary-rules.json`保存与前作术语配套的常用语境规则。翻译直接读取本作规则；整作审校后，将可供后续作品参考的必要规则提升到公共规则中，并保留作品适用范围。

翻译必须同时读取公共表和本作表。公共表保持系列一致性，本作表补足当前剧情；同词异译必须复核，不默认本作表覆盖公共表，也不拿公共译法直接抹去本作特殊语境。公共已确认术语优先复用，特殊覆盖需明确记录。

## 章节筛选

```powershell
.venv/Scripts/python.exe tools/select_glossary.py --game <作品ID> --script <脚本名>
```

输出分别包含public、local、public_rules、local_rules和conflicts。同原文出现不同译法会明确报告；相同译法仍保留两侧信息，便于核对本作备注。工具始终读取本作表，不只查公共表或本作表的来源链接。

全半角、跨碎片匹配仅用于产生候选，不证明人物身份。别名匹配可能误报或漏报，需结合上下文。处理较早作品时，工具按series.json作品顺序过滤后来作品首次收录的公共条目，避免后作信息进入前作。

## 状态与生命周期

本作新增术语先留本作表，确认并完成审校后提升到公共表，供后续作品继承；整个术语表及相关规则都在归并范围内。最迟在宣布完成或发布前完成归并。暂译和未确认条目留在本作，不作为公共定译。

公共project_locked表示前作锁定译法；preserve_in_context表示语境内保留原词。本作confirmed_local表示本作已确认采用，是否已晋升由公共来源引用核实；provisional表示暂译；旧表未声明状态的条目在筛选结果中标为local_locked，不据此自动提升。

first_recorded_game仅表示最早收录，不等同首次登场。姓名简称、旧姓、化名、同形词和剧透条件必须保留。原始表内的继承快照及旧备注不自动覆盖新版公共决定。

## 来源与检查

source_refs仅作辅助追溯，直接指向各作已有锁定表；不要求公共表复制所有原始字段或为每条本作新记录建立索引，也不另存整份旧表。

```powershell
.venv/Scripts/python.exe tools/check_series_glossary.py
```

检查公共表已声明的来源、译法、别名及前作规则。本作暂译及仅适用于本作的规则不要求与公共表完全一致。更新公共表不自动改写前作译文。
