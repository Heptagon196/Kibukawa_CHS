癸生川网页番外汉化（Portable）
================================

解压 ZIP 后，双击“Kibukawa-Web-Spinoffs-CHS.exe”即可运行，无需安装。

收录作品按发布时间由早到晚排列：
1. 诞生纪念日事件
2. 狭稻温泉乡杀人事件（原作未完成）
3. 运行测试事件Ⅱ

三部作品的游戏资源与网页运行器位于同目录的 www 文件夹，游玩时无需联网。
请不要把 EXE 单独移出文件夹，否则应用无法找到网页资源。

运行要求：
- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime
  Windows 11 及多数较新的 Windows 10 系统一般已经自带。

说明：
- 各作品的存档相互独立。
- 本汉化尚未逐一通关所有分支。
- 狭稻温泉乡篇的原作正式流程止于第四章；第五章是原作未完成草稿。
