仮面幻想殺人事件 简体中文补丁 — BepInEx 版

本包包含 BepInEx 5.4.23.5 Windows x64 框架、Kibu1ZhCN 1.0.32 插件、译文及正文点阵字库。
正文按行宽换行，允许标点位于行首及左括号位于行尾，不再为避让标点回移已显示文字。
制作人员名单及最终落款保留原始换行和缩进，逐行验证姓名、公司名的宽度，不套用对白片段合并。
网游聊天每条消息另起一行，保留不同发言者的分隔；消息内部仍按中文行宽自动换行。
调查解锁新增选项时，同一菜单的不同脚本版本共享最近选择；选项重排或解锁新对白后仍跟随该选项。
游戏内菜单分别记住本次运行中上次选择的位置；原选项消失时回到第一项。退出游戏后重置，不修改存档。
适用本工作区提取时的原版 kibu1.exe（Unity 2019.4.9 / Mono x64）。

安装：
1. 退出游戏。建议复制完整游戏到独立目录进行测试。
2. 将本包内容解压到副本的 kibu1.exe 同级目录，结构应为：
   kibu1.exe
   winhttp.dll
   doorstop_config.ini
   BepInEx/core/...
   BepInEx/plugins/Kibu1ZhCN/Kibu1ZhCN.dll
   BepInEx/plugins/Kibu1ZhCN/translations.json
   BepInEx/plugins/Kibu1ZhCN/translations.bin
   BepInEx/plugins/Kibu1ZhCN/fonts/...
3. 从该目录启动游戏，插件会加载中文译文。
4. 日志位于 BepInEx/LogOutput.log；首次运行后生成
   BepInEx/config/local.kibu1.zhcn.cfg。

如果目标已安装 BepInEx，请先备份已有加载器和配置，避免覆盖其他插件所需的版本。
本包针对原始资源；旧版离线回填补丁须先恢复为原版资源和 Assembly-CSharp.dll。
插件会校验原版资源版本，匹配失败时停用汉化并记录日志。

机制：
剧情在原脚本解码后按场景、指令位置、字符串参数槽替换。
界面通过本地化键、显示文本和 Harmony 运行时 IL 替换加载译文。
不覆盖游戏资源或原始程序集，不改变脚本长度、跳转地址及存档偏移。
正文统一使用标准版 GNU Unifont 16.0.04（非日文字形版）。
汉字、英文、数字、标点及半角假名均使用此字库，不再混用原日文字体。
原生字高 16px：汉字通常为 16×16，英文和数字为 8×16。
按原生像素宽度绘制，保留游戏原有半角/全角字距，不拉伸或抗锯齿。
外层时钟、日期和纯英文/数字界面仍沿用原像素字体；此改动统一的是正文渲染。
中文界面单独设置行距并适配文本框，静态正文按实际整行字宽进行构建校验。
FontNames 仅控制中文外层界面与动态缺字后备字体；正文使用打包的点阵图集。
可关闭 ReplaceFont 停用字体处理。字库来源、固定版本及许可随包附在插件目录。
4 页操作说明以运行时中文界面覆盖原图片文字，保留原边框、翻页与关闭操作。
包括手柄、键盘、复刻项目介绍及注意事项。其他图片内嵌文字未重绘。
人物姓名去掉片假名读音；纯读音碎片以空字符串替换，原脚本槽位与控制指令保留。
正文按中文实际字宽重新排版：取消原文无标点处的换行，标点后的换行可以保留。
每行最多20半格（10个汉字）且不超过20字符，闭标点与前面的文字连排，颜色片段共用同一行宽。
行数按一次点击推进的对话计算：无姓名最多5行，有说话人时最多4行。
原确认等待后只重置新对话的行数预算，不清屏。保留原向下续排及滚动：需要空间时仅滚走已读历史。
仅本次未读内容自身超过容量时追加确认等待，随后继续滚动。清屏只由原脚本决定，姓名、颜色与原有等待操作保留。
保留原逐字显示、颜色和等待操作；说话人姓名在自动分页时保留。
构建回放全篇正文，并独立检查全部姓名、菜单宽度和菜单行数。
原始脚本字节、指令地址及存档偏移不变。

停用：退出游戏，在配置中将 Enabled 改为 false 后重新启动。
卸载本汉化：退出游戏，仅移走 BepInEx/plugins/Kibu1ZhCN 文件夹。
如还使用其他 BepInEx 插件，请保留框架及其他插件。

验证范围：编译、原始指令离线回放、挂钩签名/IL 定位和打包校验。
此前已通过游戏加载日志及用户中文画面验证；1.0.10 的正文重排等待用户画面复测。
遇到问题可提供 LogOutput.log；此版不自动截图或操作游戏。
本安装包不包含游戏本体，也不会自动安装到原游戏目录。
