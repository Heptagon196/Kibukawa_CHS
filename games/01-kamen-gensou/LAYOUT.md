# 第一作回填与排版约束

供提取、回填、插件和校验代码维护使用，不作为 AiNiee 语言风格提示词。

- 正文所有字符，包括英文、数字和标点，统一使用中文 GNU Unifont 16px 点阵字库。
- 正文宽度20半格（10个汉字），保持原44px左侧起点和右侧留白；每行受20字符缓冲限制，各脚本槽位最多20个 UTF-16代码单元。
- 普通正文无标点处的原始折行交由重排，标点后可保留合理换行。闭标点不能被折行孤立推到下一行，跨颜色片段同样处理。
- 原始点击等待之间的未读正文最多5行，有姓名行时正文最多4行。不能把历史文字计入本次容量，也不能跨原等待移动词句。
- 点击只重置未读预算，不新增清屏。保持向下续排与滚动，仅滚走已确认读过的历史；本次自身超限才追加等待，复核其必要性和断点自然度。
- 选项每项最多8半格（4个汉字），包括英文、数字及标点实际占宽；同时检查单项与整行。Taclimax 的8个 ASCII字母符合该限制。
- 聊天换人是结构性边界；制作名单和结尾固定画面保留原换行、缩进与计时，独立检查，不能按普通对白合并。
- 保留原索引、控制结构、颜色对象和存档偏移；姓名注音空字符串只限精确白名单。
- 构建检查全文字宽、行数、缓冲、文字完整性、原点击边界及额外等待位置。点击审校基线只在对照原文复核后更新；实机效果由用户验证。

上述数值仅对第一作验证，后续作品不能直接沿用。
