# 翻译交付约定

本文件描述数据交付，不作为语言风格要求。

- 每批输出 JSON 数组：[{"text_index":编号,"translated_text":"译文"}]，与所分配索引一一对应，不修改 source_text、索引或其他任务数据。
- translation_status=7 的保护条目不翻译；保留格式占位符、控制标记和必要格式。
- 理解完整发言后，在同一次原始确认等待内分配译文片段，不将词句跨等待挪动。边界信息不足时记录待核对，不按相邻索引猜测。
- 本作脚本槽位最多20个 UTF-16代码单元，不插入换行、制表符或NUL。这是存储限制，不是句长要求，不得为凑槽位删改原意或填无意义空格；无法合理分配时交给回填环节处理。
- 一般条目不能留空，仅精确白名单中的纯姓名注音片段允许空字符串，不得以 null 代替。UI 原有合法换行按数据类型保留。
- 输出位置由本批任务指定。并行任务只写自己的译文与审校文件，由主任务合并；不得直接改公共缓存、原文清单或锁定术语。
- 新词、歧义和线索疑点另记审校文件。修改已审校发言必须重新对照原文，不能自动刷新点击边界基线。

回填环节见 [技术约束](../LAYOUT.md)，不以自动检查代替语言审校。
