# 统一标题母版（2026-09-19 修订）

唯一采用的完整母版：`../artwork/title-master-v2.png`。通过内置 imagegen 参考原版 `065-title2.png` 生成一张完整标题画面；不采用单字生成结果，也不把普通UI的12px字体用作标题艺术字。

程序 `scripts/title_art_parts.py` 从同一母版提取中文菜单、系列名和后篇标签；`scripts/build_title_components.py` 将共用部分复用于三张240×240标题，只保留原版各自版权及后篇标记差异。共用区域逐像素一致性由断言及回归测试验证。354×354外层封面保持自身原布局并复用整行系列名部件。

bg21不再替换。早期artwork文件及单字实验不参与当前打包。

生成提示词：以完整原版title2为参考，生成一张完整简体中文母版；保留黑底、红色枝状装饰、永劫会事件书法及边框符号，右侧小字匹配原图楷书/笔锋风格，不使用无衬线字体；右侧“侦探·癸生川凌介事件谭”，三个艺术字菜单“开始／玩法说明／附加内容”，后篇标签及原版权。一次生成整张母版，之后程序拆分复用，不分别生成三个标题。

运行时字体另行限定：原带注音行的正文和正文姓名栏16px，其余原生文字保留原版字号。图片插件延迟到第一次标题绘制才调用依赖StScreenManager的CreateImage。

菜单背景修复：三张标题保留母版的完整菜单区域，不再擦字、缩放重贴菜单或覆盖黑色矩形。`build_title_panels.py` 在原位只调整选中字形亮度，生成 3×5 张含完整背景的动画面板；运行时于 (27,34) 一次绘制整个 76×91 区域，覆盖原生残留动画。15 个状态的非字形像素与母版逐像素一致，三个选项的全部 8 个动画阶段均有离线覆盖。

图片插件1.0.4：完整面板不再永久复用首次进入时创建的屏幕资源；标题背景实例更换或任一面板/纹理失效时重建。离线用真实的静默跳过失效纹理行为复现，并覆盖连续三次返回与资源释放。角色姓名标签不注册替换路由，完整使用原图。
