《侦探·癸生川凌介事件谭》第3卷《死者乐园》简体中文 0.2.2 测试包

需正版 Steam 第三作 kibu3.exe。退出游戏后，将 package 内全部文件解压到 kibu3.exe 同目录，再正常启动游戏。请勿放入第一作或第二作目录。
完整包包含 BepInEx 5.4.23.5 x64、独立插件、译文和 GNU Unifont 点阵字库。不会替换原程序集、剧情资源或存档。原游戏指纹不符时插件停止加载。

字体、对白重排、菜单短名和四页帮助均在运行时生效。正文译文保持完整，仅菜单使用按宽度审核的短标签。标题美术及其他游戏内烘焙图片尚未逐一汉化。
这是离线验证后的实机测试包，实际视觉效果请用户确认。遇问题请提供 BepInEx/LogOutput.log 及场景描述。

临时停用：把 BepInEx/plugins/Kibu3ZhCN 移出游戏目录。
若无其他BepInEx插件，完整卸载本包时可移除本包添加的BepInEx、doorstop_config.ini、winhttp.dll；不要删除游戏原始文件。有其他mod时不要整目录移除BepInEx。
