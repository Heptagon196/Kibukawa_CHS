侦探·癸生川凌介事件谭 第八作《假面幻影杀人事件》简体中文测试补丁 0.4.26

本包使用 BepInEx 5.4.23.5，仅适用于 kibu8.exe 的已验证 Unity Mono 版本。
将本包内容放入 kibu8.exe 所在目录后，照常从 Steam 启动游戏。
正文、脚本菜单和已提取界面文本已接入中文。
附带图片替换插件 1.2.3：三篇中文标题、三个菜单高亮、外壳封面、设置背景及十种操作图标（含选中和未选中状态）。
附带历史记录插件 1.6.3：H / PageUp 或空闲时原生左软键打开；Esc 关闭。
历史仅收录已显示文字，打开时暂停剧情；保留姓名及文字颜色。
长译注在读到对应行时使用独立可收起的注释栏显示。
中文行不绘制原日语振假名；原始ruby数据保留在原脚本和仓库研究材料中。

游戏程序集、脚本资源、跳转地址和存档格式保持原样。
中文只在内存显示缓冲和最终界面绘制处替换。
当前经过离线构建、指纹和结构验证，实机显示效果由用户验证。
日志：BepInEx/LogOutput.log。插件开关：BepInEx/config/local.kibu8.zhcn.cfg。
禁用插件可在游戏关闭时将 BepInEx/plugins/Kibu8ZhCN 移出 plugins 目录。
使用配套安装脚本时，完整恢复信息和旧文件备份保存在系列仓库本作 installations 目录。

竖排文字选项、设置页、加载条和顶部时间地点栏使用 12px native small-font Font 2026.07.20 原生像素字形，保留完整笔画及基线；少量缺字使用明文补充字形。正文及其它游戏绘字位置使用 GNU Unifont 16.0.04。许可证随补丁附带。
发行包仅包含运行资源、使用说明与许可证。translations.json 可读译文副本、字体构建材料与图片预览保留在仓库或本地构建目录，不随补丁分发。
修改译文请修改仓库正式译稿并重新构建；插件读取 translations.bin。
译文包沿用系列 schema 1 / KBZH 格式和公共读取器，存储纯文本。颜色与控制信息由适配层从原脚本读取。

带返回功能的文字选项也复用原作光标记忆表，记录上次确认的位置；不新增存档数据。
