# 第八作批次翻译

先读系列 `series/style.md`、`series/GLOSSARY.md`、`series/glossary.json`、`series/glossary-rules.json` 和本作 `work/glossary.locked.json`。新增术语提案会在 `work/glossary-candidates.json`，存在时一并读取；不改变前作锁定称呼。

只编辑被分配批次的 `work/batches/NN.zh-CN.json`，以 `NN.source.json` 为源。保持全部 id、kind、source 和条目顺序，填写 target。可添加 notes 说明歧义/文字线索/词名依据。不要修改其他批次、缓存、共享表或游戏。不操作游戏窗口。

按场景连读，逐完整发言理解，再翻译条目。对白用中文“”，引号按整段发言闭合，不能逐物理行重复加引号。数字、否定、推測、时间和角色知识范围不改变；错误选项依原文错误保留。

所有 `<color=N>...</color>`、`<ctrl=XX/>`、`<row/>` 标签的数量和顺序完全保留。颜色值可能由脚本重定义，勿自行命名颜色。ctrl 位于对应文字之后；它是点击/清屏等执行边界，不能移动内容穿过 ctrl。row 是原文物理行：相同颜色且没有 ctrl 时可以在邻接 row 内调整中文语序、留空某一行，但保留 row 标签和完整单元内容，不能牺牲自然中文硬拆日语词序。禁止把整句文本按字数跨颜色段分摊。源码的空字形已从展示文字去除，原始槽位和所有平面保存在研究回放。

普通人名不加注音；姓名牌按原称呼，不能补成揭露后的真名。新专名采用有依据的汉字简化或简明音译，疑点记 notes。标题暂译假面幻影杀人事件，注意不是前作假面幻想杀人事件。林居、尾Q、生王正生、白鹭洲伊纲等沿用公共表。

雪海豚的文字风格：初见时有伊纲逐句解释的发言，用明显的中文火星语与拆字，体现“难读、需要解释”的效果；伊纲的转述保持正常中文。后续按原文变形程度减轻，只保留可读的网络口吻，不把原本正常的句子强行变形。初见部分使用用户指定的 https://ebtool.com/zh-CN/martian/ 中模式转换正常中文；按用户最新要求保留该模式输出的假名、注音及异体字，不另做过滤。保留原意、颜色强调及执行标签，构建时检查新增字形覆盖。

每批必须完整翻译并自审：先连读中文自然度，再逐项对照原文的漏译/增译、颜色强调、点击边界及术语。不要使用外部机翻服务或以字符替换冒充翻译。可以对确认同语境的完全相同界面标签复用译文。长批次分块落盘，避免一次输出过大丢失进度。

结构验证可导入 `scripts/translation_io.py` 的 check_target(source,target)。它只检查标签结构，不代表语义已经审校；不要创建自动批准的点击/颜色基线。完成后回复条目数、疑点和新增术语。
