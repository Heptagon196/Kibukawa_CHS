第六作《对交错事件》知识参考组件 0.1.0

本包只添加右侧“知识参考 ↗”按钮，不包含整作汉化。
在游戏退出时，将 package 内容合并至第六作游戏目录。
按钮位于右侧下方，点击后由默认浏览器打开随包提供的离线参考页。
需要 Windows 已安装的微软雅黑或黑体。依赖游戏现有的 Unity EventSystem。
查阅后切回游戏。此组件不主动暂停游戏，不改变原游戏失焦行为。
卸载：游戏退出后移除 BepInEx/plugins/Kibu6Reference 文件夹。

内容：假名与罗马音、行与段、折叠的日文手机键盘对照。
不包含人物名单、数值推导、谜底或后续剧情。
现有译文与人物读音注释保持原样，避免在整作界面尚未接入时丢失必要线索。

已完成离线编译和打包检查；未启动或操作游戏。
待用户实机确认：不同窗口大小下右侧按钮是否遮挡原界面、中文字形、点击打开本地页、返回游戏后的输入。
实现为第六作独立叠加按钮，不修改原生菜单导航或新增引擎 adapter。
