九键拼音本地化版 1.0.9 — 供实机验证

退出游戏后，将本包内容合并到 GmodeArchivesPlus_kibu6 游戏目录。
正常通过 Steam 启动游戏即可。安装与构建工具不会启动游戏。

包含完整提取文本汉化、运行时挂钩、16px点阵中文字库、中文菜单与系统界面、
五页中文帮助、中文标题图片，以及必装的历史记录插件。已去除独立参考按钮与HTML页面。
Esc 设置菜单左侧保留原菜单，右侧显示九键拼音表；“游戏帮助”中也保留九键图。
九键按键图在原有“游戏帮助”菜单中，不会打开外部浏览器。

本汉化将原日语文字谜题改成汉语全拼九键谜题，联动修改数字、化名和开场暗号。
没有译注；无需日语知识。建议从头开始，以免混用旧方案线索。
原资源和程序不被覆盖，原脚本跳转与存档地址不变。

已离线检查全文、原引擎读指令/跳转/文本缓冲、菜单挂钩、换行和字体覆盖。
尚未代替玩家进行实机通关。请确认对话/菜单/证物卡显示、五页帮助、标题，
以及开场暗号、五道姓名题、末尾化名推理是否正常。

历史记录：按 H / PageUp 打开；左软键无其他功能时也可打开。Esc 关闭，滚轮或上下键翻阅。
