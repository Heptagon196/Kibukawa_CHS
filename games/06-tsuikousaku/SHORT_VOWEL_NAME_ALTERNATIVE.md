## 数字链

九键采用 2 ABC、3 DEF、4 GHI、5 JKL、6 MNO、7 PQRS、8 TUV、9 WXYZ。完整拼音按字母逐个求和，重复字母重复算。

- BIQI = 2+4+7+4 = 17。
- XILI = 9+4+5+4 = 22。
- YIBI = 9+4+2+4 = 19。
- QI = 7+4 = 11。
- XI = 9+4 = 13。
- JILI = 5+4+5+4 = 18。

17+22+19+11+13+18=100。

100 → 83 → 61 → 42 → 31 → 18 → 0。

吉利与吉里均符合读音规律且和值18，保留替代目标关系。末位筛选仍限定未遇害者；未验证原作完整调查名单，不声称已排除所有名单人物。

先观察姓名读音，姓／名二选一题干不报差值、不暗示手机。答对后指出韵母均为 i。随后依原作先提出从100逐次减数的假设，核对姓名与差值；最后以文字输入选择题揭示九键求和。100是保留原作的起点假设，不声称只凭遗体数字就能唯一推出100。
