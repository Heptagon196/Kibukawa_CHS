## 声音规律及答题

选中部分每个字的韵母均为 ian，且实际拼音直接包含 ian。不采用“都含字母 a”的宽泛规律，也不采用岩、彦等需要解释 yan 拼写的字。

五道题先只比较读音：

1. 田边 / 广美：选田边；广美为 guang mei。
2. 内野 / 千怜：选千怜；内野为 nei ye。
3. 浅见 / 康司：选浅见；康司为 kang si。
4. 夏目 / 健典：选健典；夏目为 xia mu。
5. 松井 / 千弦：选千弦；松井为 song jing。

每题恰好一项符合“两个字均押 ian 韵”。对应原程序的正确索引仍为 [0,1,0,1,1]。

第一轮题干不报差值、不提示手机，也不解释生僻字读音。答错提示可恢复原意：“这一步和数字无关。把名字念出来，或写成拼音，再比较一下读音。”

期望保留三层揭示：发现姓名读音共同点 → 发现姓名与遗体数字的关系 → 识破手机按键求和。

## 数字验算（仅证明算术成立）

采用标准九键分组 2 ABC、3 DEF、4 GHI、5 JKL、6 MNO、7 PQRS、8 TUV、9 WXYZ。按完整拼音逐字母求和，不计声调，重复字母重复计算。

六次扣数为 34、36、36、32、40、36，总和为214：

214 → 180 → 144 → 108 → 76 → 36 → 0

前间 QIANJIAN = 7+4+2+6+5+4+2+6 = 36。
片见 PIANJIAN = 7+4+2+6+5+4+2+6 = 36。

二者既同韵，又有相同数值，可以保留替代目标关系。已经遇害的千怜、浅见也为36，因此后续筛选须限定尚未遇害的人。未取得完整调查名单，不能声称已检查名单所有人物。

## 暂缓原因与未解决事项

用户认为214作为减法起点不自然，因此要求先保存，不落实。

214是根据当前姓名键值总和倒推得到的设计数，不是已经证明能由前期线索自然推出的答案。不能让角色毫无依据地先报出214。

“180加田边的34得到214”只说明算术成立；如果此时尚未揭示键盘算法，田边的34又是从214减180而来，就会形成循环推理。此解释尚不能解决剧情问题，不能写作已解决。

后续如继续，应先解决起点依据与揭示顺序，再改正式译文、颜色段基线、答题回显、数字卡、术语表和测试。不得为了保留某个起点而再次放宽押韵要求。
