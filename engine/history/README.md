# 癸生川系列历史记录插件 1.6.1

适用 Steam 第一至第五作（第四作包含前后篇），需要 BepInEx 5 / Windows x64。独立插件，不修改原游戏程序集或存档。

- 游戏左软键 L（左肩键、原游戏绑定的键盘 Q / L）：原提示为“---”时显示“历史记录”，按下即可打开，不再要求正在显示对话。原本有“返回”等功能时保持原提示和操作。历史打开后再按一次肩键关闭。
- 鼠标左键不再打开历史记录；窗口内仍可点击关闭按钮、拖动滚动条。
- H / PageUp：保留键盘开关快捷键。
- 上下键、游戏映射的十字键/摇杆、鼠标滚轮、滚动条：浏览。上键不打开历史。
- 每次打开自动到底部；Esc、H / PageUp 或关闭按钮退出。
- 打开时暂停游戏并隔离输入；关闭后立即恢复速度，不设重新打开的冷却时间；只消费关闭当帧的输入，避免同一次操作传入游戏。
- 保留本次运行最近 2000 段已执行文本；退出游戏清空。当前已送入打字缓冲区的片段可查看，不读取未执行的剧情。读档后继续追加。
- 保存每个已记录字符当时的 RGB 颜色，说话人和同句变色内容按原色显示，颜色跨自动换行保留。已记录颜色不受后续调色板变化影响。
- 正文与滚动条置于独立深色面板，四周有描边和内边距。

复用游戏左软键事件 21 与上下方向状态 17 / 19，滚动使用未缩放时间。

左肩键提示直接读取当前游戏画布的实际 L 标签，同时保留替换前的“---”；游戏更新为有效功能时立即使用原操作。非游戏画布、暂停菜单等无法打开历史的状态不替换提示。

安装：将对应 ZIP 内的 BepInEx 文件夹合并至游戏目录，然后启动游戏。

卸载：退出游戏后移除 BepInEx/plugins/KibukawaHistory 文件夹。

构建：工作区根目录执行 `.venv/Scripts/python.exe engine/history/build.py`；输出 `out/history/kibu*-history-1.6.1.zip`。包内仅有插件 DLL、说明及 MIT 许可证。

验证：五作编译与挂钩元数据检查，历史容量/颜色/协程暂停，肩键按下释放与滚动，以及空闲提示替换、恢复、切换到有效操作和未知状态回归。实机界面效果需启动新版确认。
