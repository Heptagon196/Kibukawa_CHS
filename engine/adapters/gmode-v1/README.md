# G-MODE v1 适配器

负责文本缓冲、滚动、菜单状态与点阵字体绘制，供兼容作品复用。各作的挂钩入口、聊天边界、固定名单范围、帮助页和字符串地址由作品插件维护。引擎容量与字段约束须按对应原程序集验证，不能直接套用到未经检查的续作。

DialogueReflow 按行宽与缓冲容量换行，不做行首/行尾禁则，也不为后续标点回搬已显示的字符。保留语句边界、颜色、逐字显示与分页保护。

结构换行跟踪实际执行的原文行、颜色及77/78边界：整行非默认同色文字后，恢复默认色并开始引号对白时保留换行；正文彩色关键词不强制换行。此规则不依赖游戏地址、姓名或特定颜色编号。

作品通过各自构建脚本选择公共组件，并用原程序集回放和排版用例验证。支持范围、差异与实机状态见各作的 COMPATIBILITY.md 和交付记录；离线验证不能代替实机验收。
